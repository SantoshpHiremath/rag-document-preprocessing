Signal Fault Codes

This article lists common fault codes reported by trackside signal controllers and the recommended first response for each.

Code SF-102: Loss of Communication

Indicates the controller has not received a heartbeat from the central interlocking system for more than 30 seconds. See the heartbeat timeout guide for diagnostic steps.

Code SF-207: Battery Voltage Low

The backup battery has dropped below the 11.5V threshold. Dispatch a field technician within 24 hours. Full procedure in the battery replacement article.
